# Portiva — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Chief strategy officer

- As a CSO, I want all AI bets on one portfolio scored by moat and policy risk, so that I can stop funding theatre.
- As a CSO, I want pre-agreed kill metrics enforced at stage gates, so that failing pilots die on evidence.

### Domain sponsor

- As a retail banking sponsor, I want to propose a customisation/engagement bet with a clear value metric, so that it competes fairly for capital.
- As an operations sponsor, I want CoE-as-a-service candidates flagged separately, so that we do not confuse cost take-out with new revenue.

### CIO / head of AI

- As a CIO, I want vendor concentration across the portfolio, so that we do not accidentally outsource systemic capability to one cloud or model provider.
- As a CIO, I want talent demand aggregated from scale decisions, so that HR reskilling matches the roadmap.

### Model risk / conduct liaison

- As a model-risk liaison, I want policy blockers visible before scale approval, so that compliance is not a last-week surprise.
- As a conduct liaison, I want self-driving-advice initiatives tagged for accountability framework gaps, so that we do not scale unowned customer outcomes.

### CFO partner

- As a finance partner, I want realised vs expected value by stage, so that we recycle capital quarterly.
- As a finance partner, I want overlapping pilots merged or killed, so that we stop paying twice for the same outcome.

### Board risk committee

- As a board member, I want a one-page portfolio heat map of AI systemic and conduct exposures, so that oversight is possible without reading forty charters.
